Do I need API keys?

Gemini is recommended for selecting and ranking moments. Deepgram or ElevenLabs can provide cloud transcription; local Whisper is available as a fallback. Zernio is optional for publishing and scheduling.

Does ClippyMe host my videos?

ClippyMe is designed to run on your hardware. Clips, settings, and keys stay in local folders. Review the security and deployment documentation before exposing any service beyond localhost.

Can it automatically clip live streams?

Yes. Live Monitor supports YouTube, Twitch, and Kick capture workflows. Available capabilities differ by source and mode; see the repository documentation for setup details.

Is publishing included?

Publishing and scheduling are integrated through Zernio. Provider subscriptions, API quotas, and social-platform limits still apply and are not bypassed by ClippyMe.
